# CounterIQ - Web Dashboard

Next.js 15 App Router. Tailwind. shadcn/ui. Supabase Auth.

This directory will hold the dashboard generated by Lovable from
`/prompts/LOVABLE_DASHBOARD_PROMPT.md`. After Lovable generates the project,
clone or download it into this directory.

## Setup

```bash
pnpm install
cp .env.local.example .env.local   # then fill in
pnpm dev    # http://localhost:3000
```

## Required env vars

```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=     # server only
NEXT_PUBLIC_APP_URL=http://localhost:3000
ANTHROPIC_API_KEY=             # daily report cron
RESEND_API_KEY=                # email
TWILIO_ACCOUNT_SID=
TWILIO_AUTH_TOKEN=
TWILIO_FROM_NUMBER=+1...
R2_ACCOUNT_ID=
R2_ACCESS_KEY_ID=
R2_SECRET_ACCESS_KEY=
R2_BUCKET=counteriq-clips
```

## Privacy linter

`packages/shared-types/banned-words.ts` exports the regex used by IncidentCard,
ReportViewer, and AlertSettingsForm. Banned words at component layer fail
the build.

## Deploy

Push to GitHub -> connect to Vercel -> set env vars -> deploy.
